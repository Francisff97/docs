# BaseForge — User Guide

Source of the user documentation for **BaseForge**, a platform that lets Base Builder communities sell packs and coaching sessions online. Built with **Docusaurus**.

Live docs: https://docs.base-forge.com

## Getting started

```bash
npm install
npm start        # local dev server
npm run build    # static build in /build
```

## Structure

```
docs/                  # guide pages (Markdown)
src/                   # custom pages and styles
static/                # images and assets
docusaurus.config.js   # site configuration
sidebars.js            # sidebar navigation
```
